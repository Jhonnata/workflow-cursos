# Workflow Cursos

Aplicacao web para modelagem e visualizacao de workflows relacionados a cursos, turmas e aprendizes.

## Principais recursos

- editor visual baseado em fluxo para montar regras e conexoes
- gerenciamento de condicoes e evolucao de turmas
- visualizacao de workflows e dados associados
- autenticacao e navegacao por rotas da aplicacao

## Tecnologias

- Vue 3
- Vite
- Vue Router
- Vue Flow
- Tailwind CSS

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
